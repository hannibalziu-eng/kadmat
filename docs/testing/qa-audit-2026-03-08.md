- Remaining skips are concentrated in:
  - `forgot password` flow under limited semantics

Impact:

- Reduce `skip` gating in `data-consistency`, `network`, and `responsive`.

### P3 - Network and performance flakiness in the harness is now controlled, not eliminated
During hardening, the biggest instability came from:
- Supabase session bootstrap timeouts/ECONNRESET
- strict local latency assertions that forced redundant login/token work

Fixes applied:
- stronger retry/backoff in `/Users/wew/Desktop/kadmat/e2e/playwright/src/helpers/browser-auth.ts`
- `performance.spec.ts` now reuses the token returned by `auth/login` instead of triggering a second auth path
- fallback navigation checks in `customer-flow` and `navigation` now validate real shell/API behavior without redundant direct API calls

Impact:
- The suite is stable enough for local regression use.
- Cold-start latency should still be watched on constrained browser profiles.

Recommended fix:
- Keep a softer local budget for `mobile-webkit` than desktop browsers.
- Investigate cold-path latency only if it starts failing consistently again.
